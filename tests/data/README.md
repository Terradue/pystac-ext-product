# Product schema fixture

`product-v1.1.0-schema.json` is an unmodified copy of the upstream
[Product schema](https://github.com/stac-extensions/product/blob/main/json-schema/schema.json),
retrieved on 2026-10-05 with schema identifier
`https://stac-extensions.github.io/product/v1.1.0/schema.json`.

Tests cache this snapshot in PySTAC's validator to validate extension metadata
without network access. These tests validate the extension contract, not STAC core.
The upstream schema is distributed under Apache-2.0.
